# Plastic Soldier

A separate design with classic Minecraft player proportions, scaled to half a block in height. It has eyes and a belt buckle, without a cap.

- Editable model: `blockbench/plastic_soldier_player.bbmodel`.
- Source texture: `textures/plastic_soldier_player.png`.
- Preview: `previews/plastic_soldier_player_preview.png`.

No animation tracks or NeoForge export are included for this design.
